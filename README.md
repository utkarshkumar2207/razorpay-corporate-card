# RazorpayX Corporate Card — Interactive 3D Showcase

An interactive, high-fidelity 3D web experience showcasing the RazorpayX Corporate Card built for startups. Powered by **Three.js** and **GSAP ScrollTrigger**, featuring real-time lighting, interactive mouse parallax, responsive viewport physics, and continuous storytelling flip animations.

## Features
- **3D Interactive Corporate Card:** Built with Three.js WebGL rendering, custom matte PBR textures, rounded bevel geometry, and realistic card thickness.
- **Scroll-Synchronized Storytelling:** Fluid, velocity-capped card rotation and translation transitions synchronized across feature sections.
- **Responsive Layout:**
  - **Desktop:** Split-screen layout with interactive text flow on the left and sticky 3D canvas stage on the right.
  - **Tablet & Mobile:** Top-anchored 3D card stage with background feathering and scrolling content underneath.
- **Interactive Perks Matrix:** 3D flipping perk cards showcasing startup rewards (Google Workspace, AWS, Meta Ads, Shopify, Freshworks, Notion).

## Tech Stack
- HTML5 / Modern CSS
- JavaScript (ES6+)
- [Three.js](https://threejs.org/)
- [GSAP & ScrollTrigger](https://greensock.com/)
- [Lucide Icons](https://lucide.dev/)
